| 项 | 内容 |

## 三、ch0 六幕剧情线

### 第一幕 · 木屋之醒（`01_01.txt`，关卡 intro）
白柯行以在陌生木屋的床上醒来。天花板是陌生的木纹，记忆像被水泡过的纸——只剩自己的名字抓得住。屋里有人生活过的痕迹，床头（或墙角）立着一座**停住的钟**，指针停在同一个位置，像被谁按下了暂停。Door 的提示亮起，出门即进入第二幕。

- **演出要点**：`whiteout 0` 黑场入 → `hide 0` → 旁白建立异样感 → bkxy 首句自白 → 注意到停钟（伏笔一）→ `whiteout _` 收尾，交还控制权。
- **结尾钩子**：`tip` 提示四处探索。

### 第二幕 · 木屋之寻（`01_02_bed / _drawer / _clock.txt`，家具交互，可跳过）
- **床**：被褥残留体温。"有人刚离开——或者，刚把床让给你。"（细思极恐的甜点）
- **抽屉**：一柄**破旧的短剑**（broken_sword，初始武器叙事化）。"不太体面，但握着让人安心。"
- **钟**：可取走。指尖碰到钟摆的一瞬，幻听一声遥远的犬吠（伏笔二：钟 = 石碑碎片的钥匙）。
- 三处均为一次性交互（`trigger_once`），跳过不影响主线。

### 第三幕 · 森林之遇（`02_01.txt`，关卡 intro，**已接线，本次重构扩充**）
出门，遮天蔽日的古树与斑驳光影。里德登场——知道 bkxy 名字的陌生人，自称向导。"被盯上"的压迫感中，不远处一座**散发着微光的石碑**。

- **选项 A（靠近石碑）**：符文古老难辨，里德佯装不懂。伸手触碰 → 白光觉醒。
- **选项 B（警惕环顾）**：阴影中蠢蠢欲动，严阵以待之际——石碑自行闪耀，**是它选中的你**。
- **汇合（branch 3）**：白屏、停顿、角色退场。体内的枷锁断裂，力量涌入。里德罕见地严肃：「……比上一次，快了一点。」（伏笔三：循环）。结尾 tip 指向森林深处。

### 第四幕 · 森林之初战（`02_02.txt`，巢穴前触发）
里德的教学回：移动、跳跃、普攻——用三只新手史莱姆当教具。BP 与卡牌（数字键）在战中点亮。战利品清点，里德科普史莱姆 = "回廊里的碎屑"（被打破的誓言与遗忘的碎片）。

- **演出要点**：战前短剧（约 6-8 句）+ `tip` 教学；战后不写死，交给战斗系统。
- **设计意图**：玩家在"被打"之前先听段子，降低开战的心理门槛。

### 第五幕 · 森林之苔骨（`02_03.txt`，小 Boss 前触发）
压迫感登场：比普通史莱姆大了两圈的「苔骨」，体表凝结着碑文化的纹路——它守着半截石碑碎片，纹章与木屋的钟摆**完全相同**（伏笔二回收：钟是碎片钥匙）。战后 tip 教学**下坠冲击波**（空中下坠攻击）。

### 第六幕 · 森林之吞碑者（`02_04.txt` 战前 + `02_05.txt` 终章，中 Boss）
深处，完整石碑之前，「吞碑者」盘踞。苦战提示走位闪避投掷物。胜利后石碑全面觉醒——

- **终章演出**：白屏 → 幻象：黑犬、六座石碑，五座已亮，第六座闪烁将熄 → 犬吠清晰可闻 → 里德第一次收敛全部玩笑：「……第六回了。这一次，别再忘了。」→ bkxy 收尾自白 → `title` 卡「第一章 · 苏醒之森 · 完」→ `tip`「Demo 终章 · 感谢试玩」→ end。
- ** cliffhanger**：第六座碑闪烁的含义（走完即门开，失败即第七回？）留给 ch1。

## 五、玩法完善与细化（文本侧可落地的部分）

1. **教学全嵌入**：所有操作教学通过战前/战后 VN + `tip` 完成，零新增 UI。键名在 VN 内写纯文本（`按 E 键`、`数字键 1`），因为 VN 文本框是 BBCode，不解析 `[E]` 键帽转义（那是场景提示词 WorldPrompt 的能力）。
   - **实际键位（以 player_move.gd / project.godot 输入映射为准）**：A/D 或 ←/→ 移动、Space 跳跃、鼠标左键 普攻、数字键 1/2 卡牌技能、**快速双击 A 或 D 冲刺**（无 Shift 绑定，规范文档里的 `[Shift] 闪避` 是示例性写法）、空中按 S 下坠。
2. **Boss 电影化登场**：统一 `whiteout 0` 黑场 + `hide 1` 藏对话框 → 旁白压迫 → 角色/名号亮相 → `whiteout _` 恢复开打。黑场 0.3s、停顿 1.0s 的节奏已在引擎内写死，直接复用。
3. **一次性 vs 可重复**：intro 靠 `played_intro_scripts` 自动去重；家具交互与 Boss 前奏一律 `trigger_once=true`；可重复的纯氛围交互才留默认。
4. **战斗内叙事钩子**：`tip` 是非阻塞 Toast（1.5s 自消），适合"连击提示/异常状态/掉落"等战斗内播报；阻塞台词只放在安全区。
5. **音频建议**：巢穴/Boss 战切 `bgm_ai_encounter_tense.ogg`，木屋保持 `bgm_ai_tavern_calm.ogg`（均在 StageController 检查器拖拽，无需改代码）。
6. **死亡/循环预留**：ch0 不实装死亡循环，但终章幻象已埋点；未来玩家死亡回到木屋时，`01_01` 已被 `played_intro_scripts` 标记，需要一段"既视感"短剧（建议 `01_03_déjà_vu.txt`，ch1 再做）。
7. **Debug 日志**：新增剧本相关日志遵循 `[Emoji] [模块] 动作: 数值` 规范（VN 播放起止已有 🏁/🎬 类日志的请保持）。

## 七、解析器实现备忘（写剧本必读）

以下为 `vn_parser.gd` + `vn_manager.gd` 的实际行为，与规范互补，**违反会静默出错**：

1. **注释必须独立整行**且以 `|` 开头。行内注释（`hide 0 | 显示对话框`）会被当指令解析而报错/错乱。
2. **无法识别的行被静默忽略**（不报错）。写错指令名 = 台词凭空消失，改完必须用解析器自测。
3. 每个 `choice` 的每个选项**必须紧跟一行 `goto 分支 节点`**；缺失则该选项点击后跳转到空分支 → 直接结束对话。
4. `goto` 只存在于 choice 块内；分支之间**没有**裸跳转指令。要汇合，就在分支末尾放一个单选项 choice。
5. 节点指令播完即 `end`（对话结束）。每条剧终路径显式写 `end` 最稳妥。
6. `title` / `narrate` / 带台词的 `char_action` 会**阻塞等待点击**；无台词的 `char_action` / `tip` / `hide` / `whiteout` / `pause` 不阻塞。
7. VN 文本框是 BBCode：**不要写 `[` `]` 方括号**（会被当标签），键名一律纯文本。
8. 无立绘的角色（如 reed 当前状态）照样能说话：只显示名字牌 + 台词，立绘不可见。
9. 剧本以 `whiteout 0/1` 结束会**保留黑/白幕**（防切场景闪烁设计）——除非接下来要切场景，终局一律 `whiteout _` 收尾。
10. 未知情绪词自动回退 `base.png`；但**角色 ID 写错** = 该行被当未知行静默忽略。改完剧本跑一遍解析自测。

## 八、写作规范（风格模板）

- 台词：「」全角单书名号；短句；口语但有文学质感；bkxy 可适度 meta 吐槽（穿越者自知），里德负责冷幽默与跑题。
- 旁白：现在时、感官细节、克制；一句一个画面。
- `tip`：第二人称"你"，系统口吻，≤ 20 字为宜。
- `title`：`XX · XX` 格式（如 `苏醒之森 · 初遇`）。
- 单句台词尽量 ≤ 40 字，长旁白可拆两句（`narrate` 两条）控制打字机节奏。

**验证方法与两个工程结论（供后续测试复用）**：
1. 无头环境下**合成鼠标点击到不了 Control 的 `gui_input`**（Godot GUI 点击依赖 hover 焦点，无头窗口没有真实鼠标进入事件；已用最小 Button 探针实锤）。测试 VN 请走 UI 真实入口：`ui._on_overlay_input(ev)` / 选项 `btn.pressed.emit()`，并加 0.5s 推进冷却（覆盖 `whiteout` 0.4s 等待窗口，避免管理器重入）。
2. **给贺的观察**（未改代码）：`vn_manager.gd` 的 `_process_next` 在 `whiteout`/`pause` 的 await 期间若收到 `line_advanced`（玩家在白场/停顿中点击），会重入并导致跳过一句台词。人类快速点击可触发。建议在 `_process_next` 的 whiteout/pause 分支加 `_is_playing = false` 守卫或忙位标记。剧本侧已通过节流规避测试，正式游玩偶发一句跳过不影响结构。
3. `stage_router.gd` 改名后，本地 `.godot` uid 缓存曾指向旧路径 `scene_router.gd`，导致 `--script` 模式启动报 autoload 加载失败；**正常启动不受影响**（资源扫描会按 .uid 重新解析）。若在编辑器外看到该报错，跑一次 `--import` 或重启编辑器即可。
